# 물방울 등장 동작 미리보기

바닥의 수면에서 물방울이 늘어나다가 분리되고, 아래쪽 공중에서 계속 일렁이는 모습을 확인합니다.
앱의 녹음·단축키·설정에는 연결하지 않았습니다.

저장소 루트에서 실행합니다.

```powershell
python -m http.server 8769 --bind 127.0.0.1
```

`http://127.0.0.1:8769/prototypes/liquid-droplet/`를 엽니다.
화면이나 **다시 보기**를 누르면 처음부터 재생합니다. **느리게**로 전체 움직임을 늦추거나 시간 막대로 등장 순간을 멈춰 살펴볼 수 있습니다.

- 등장 길이: 1.3초. 등장 후에는 내부 물결과 윤곽, 작은 떠다님이 계속 이어집니다.
- 크기: 이전 지름의 절반입니다. 높이 800px인 화면에서 지름은 약 74px입니다.
- 상승 거리: 처음 미리보기의 절반으로 낮췄습니다.
- 모습: 기준으로 받은 하늘빛 물방울 그림을 따라 WebGL 2 셰이더로 그립니다. 왼쪽 위의 큰 흰 반사, 흰 줄이 도는 얇은 테두리, 가운데를 가로지르는 S자 물결 띠와 그 아래 청록빛 물, 오른쪽 위에 떠 있는 작은 물방울 두 개, 둘레의 옅은 빛 번짐이 있습니다. 등장 2초 시각에 윤곽이 정확한 원이 되고 안쪽 무늬가 기준 그림과 같은 자리를 지납니다.
- 레이어: 셰이더는 화면 크기와 시각만 입력받고, 고정된 색과 투명도를 가진 물방울의 RGBA 레이어만 출력합니다. 배경색을 입력받거나 살펴보는 부분은 없습니다.
- 배경: 검은색, 어두운 회색, 밝은 회색, 하얀색 중에서 고릅니다. 캔버스 뒤의 CSS 색만 바꾸며 물방울을 다시 계산하지 않습니다. 실제 바탕 화면을 가져오지는 않습니다.
- 움직임: 점성이 있는 듯 세로로 늘어나며 연결부가 가늘어져 끊깁니다. 다 올라온 뒤에는 작게 한 번 튕기며 자리 잡고, 서로 다른 주기로 윤곽이 출렁이고 안쪽 물결 띠가 흐르며 위치도 조금씩 떠다닙니다.
- 움직임 줄이기: 운영체제에서 움직임 줄이기를 켜면 자동으로 움직이지 않습니다. 다른 탭을 보는 동안에는 그리기를 쉬고, 돌아오면 이어집니다.
- 외부 의존성이나 외부 네트워크 요청은 없습니다. 글꼴은 저장소의 Pretendard를 사용합니다.
