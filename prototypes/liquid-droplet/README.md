# 물방울 등장 동작 미리보기

바닥의 수면에서 물방울이 늘어나다가 분리되고, 화면 앞에 뜬 채 무중력에서처럼 천천히 떠다니는 모습을 확인합니다.
앱의 녹음·단축키·설정에는 연결하지 않았습니다.

저장소 루트에서 실행합니다.

```powershell
python -m http.server 8769 --bind 127.0.0.1
```

`http://127.0.0.1:8769/prototypes/liquid-droplet/`를 엽니다.
화면이나 **다시 보기**를 누르면 처음부터 재생합니다. **느리게**로 전체 움직임을 늦추거나 시간 막대로 등장 순간을 멈춰 살펴볼 수 있습니다.
**예시 화면**은 뒤에 글과 색 카드를 깔아 물방울 너머로 화면이 어떻게 비치는지 보여 주고, **렌즈**는 휘어 보이는 효과를 켜고 끕니다.

- 등장 길이: 1.3초. 그 뒤로는 멈추지 않고 계속 움직입니다.
- 크기: 이전 지름의 절반입니다. 높이 800px인 화면에서 지름은 약 74px입니다.
- 상승 거리: 처음 미리보기의 절반으로 낮췄습니다.
- 모습: 기준으로 받은 하늘빛 물방울 그림을 따라 WebGL 2 셰이더로 그립니다. 왼쪽 위의 큰 흰 반사, 흰 줄이 도는 얇은 테두리, 가운데를 가로지르는 S자 물결 띠와 그 아래 청록빛 물, 오른쪽 위에 떠 있는 작은 물방울 두 개, 둘레의 옅은 빛 번짐이 있습니다. 등장 2초 시각에 윤곽이 정확한 원이 되고 무늬와 반사가 기준 그림과 같은 자리를 지납니다.
- 움직임: 점성이 있는 듯 세로로 늘어나며 연결부가 가늘어져 끊기고, 다 올라온 뒤 작게 한 번 튕깁니다. 그 뒤에는 느리게 떠다니면서 윤곽이 말랑하게 출렁이고, 안쪽 무늬가 구슬처럼 이리저리 돌고 기울며, 겉에 비친 반사가 테두리를 따라 미끄러지고 도톰해졌다 얇아집니다. 곁의 작은 물방울도 저마다 조금씩 떠돕니다.
- 반투명: 본체는 뒤가 비칩니다. 가운데가 가장 맑고, 테두리 쪽과 색이 짙은 곳은 덜 비치며, 반사와 흰 선은 불투명합니다. 불투명도는 물방울 안의 위치와 시각으로만 정해집니다.
- 레이어: 물방울 레이어는 화면 크기와 시각만 입력받아 고정된 색과 투명도의 RGBA를 냅니다. 배경색을 입력받거나 살펴보는 부분은 없고, 배경·예시 화면·렌즈를 바꿔도 같은 시각의 RGBA는 같습니다.
- 렌즈: 물방울 너머의 뒤 화면이 가운데는 조금 크게, 테두리 쪽은 눌려 휘어 보이는 모습을 물방울 레이어 아래에 따로 그립니다(`water.frag`를 `LENS`로 한 번 더 컴파일). 테두리에서는 물방울 밖의 화면과 끊김 없이 이어지고, 뒤 화면의 색은 고치지 않고 자리만 옮겨 옵니다. 세기는 `LENS_MAGNIFY`(가운데 배율, 지금 1.4)로 정하며 1이면 휘지 않습니다.
- 배경: 검은색, 어두운 회색, 밝은 회색, 하얀색 중에서 고릅니다. 뒤 화면만 바꾸며 물방울 레이어를 다시 계산하지 않습니다. 실제 바탕 화면을 가져오지는 않습니다.
- 앱에 옮길 때: 반투명한 물방울 레이어는 뒤 화면 없이도 그대로 그릴 수 있습니다. 렌즈까지 넣으려면 물방울 뒤의 화면 그림을 가져와야 합니다.
- 움직임 줄이기: 운영체제에서 움직임 줄이기를 켜면 자동으로 움직이지 않습니다. 다른 탭을 보는 동안에는 그리기를 쉬고, 돌아오면 이어집니다.
- 외부 의존성이나 외부 네트워크 요청은 없습니다. 글꼴은 저장소의 Pretendard를 사용합니다.
