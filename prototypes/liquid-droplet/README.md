# 물방울 등장 동작 미리보기

바닥의 수면에서 물방울이 늘어나다가 분리되고, 아래쪽 공중에 자리를 잡는 동작만 확인합니다.
앱의 녹음·단축키·설정에는 연결하지 않았습니다.

저장소 루트에서 실행합니다.

```powershell
python -m http.server 8769 --bind 127.0.0.1
```

`http://127.0.0.1:8769/prototypes/liquid-droplet/`를 엽니다.
화면이나 **다시 보기**를 누르면 처음부터 재생합니다. **느리게**와 시간 막대로 분리되는 순간을 살펴볼 수 있습니다.

- 재생 길이: 1.3초. 이전보다 두 배 빠르게 재생한 뒤 멈춥니다.
- 크기: 이전 지름의 절반입니다. 높이 800px인 화면에서 지름은 약 74px입니다.
- 재질: 입체적인 반사 대신 얇은 반투명 면과 부드러운 선으로 그립니다. WebGL 2로 평면 윤곽을 계산합니다.
- 배경: 미리보기 안에서 만든 배경입니다. 실제 바탕 화면을 가져오지는 않습니다.
- 움직임: 연결부가 가늘어져 끊기고, 작은 물방울의 윤곽이 말랑하게 늘었다 줄어들며 자리를 잡습니다.
- 외부 의존성이나 외부 네트워크 요청은 없습니다. 글꼴은 저장소의 Pretendard를 사용합니다.
