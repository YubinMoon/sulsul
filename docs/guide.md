# 사용 안내

술술을 처음 설정하는 법과 기능별 사용법, 설정 파일 위치, 자주 묻는 질문을 모았습니다.
앱 소개는 [README](../README.md)에, 빌드 방법은 [개발 안내](development.md)에 있습니다.

## 처음 설정하기

1. **모델 관리 → 음성 인식 → 로컬 모델 내려받기**에서 모델과 크기를 고르고 **내려받기**를 누릅니다.
   `추천` 표시가 붙은 Whisper Large v3 Turbo(약 1.6 GB)부터 써 보세요. GPU가 없는 컴퓨터에서는 큰 모델이 느릴 수 있으니 Base(약 148 MB)나 Small(약 488 MB)이 낫습니다.
2. 처음 내려받은 모델은 바로 켜집니다. 여러 개를 받았다면 **사용 가능 모델** 탭에서 쓸 모델의 스위치를 켭니다.
3. **테스트** 화면에서 녹음하고 받아써 보며 마이크와 모델을 확인합니다.
4. 어느 프로그램에서든 **오른쪽 Ctrl**을 누르고 말한 뒤 다시 누릅니다.

창을 닫아도 술술은 알림 영역(트레이)에 남아 단축키를 받습니다. 트레이 아이콘을 누르면 창이 다시 열리고, 아이콘 메뉴에서 **끝내기**를 누르면 완전히 끝납니다.
**설정 → 일반 → 로그인할 때 자동 실행**을 켜면 로그인할 때 창 없이 트레이에서 시작합니다.

## 받아쓴 글을 보낼 곳

**설정 → 일반 → 받아쓰기 결과**에서 고릅니다.

| 받아쓰기 결과 | 하는 일 |
|---|---|
| 클립보드에 복사 (기본) | 받아쓴 글을 클립보드에 복사합니다. 원하는 곳에 붙여넣어 씁니다. |
| 커서 위치에 붙여넣기 | 입력 중인 곳에 바로 넣습니다. 입력할 곳이 없으면 기록에만 남깁니다. |
| 자동 | 입력 중인 곳이 있으면 바로 넣고, 없으면 클립보드에 복사합니다. |

- **클립보드 되돌리기**는 처음부터 켜져 있습니다. 복사된 글을 붙여넣고 나면 클립보드를 원래 있던 내용으로 되돌립니다. 받아쓴 글을 여러 번 붙여넣으려면 끄세요.
- 커서 위치에 넣을 때는 클립보드를 잠깐 빌려 붙여넣기 키로 넣고, 늘 원래 내용으로 되돌립니다.

## 단축키

**설정 → 단축키**에서 바꿉니다.

- **녹음 단축키** 칸을 누른 뒤 새로 쓸 키를 누르면 바뀝니다. **Esc**로 취소합니다.
- 키 하나(오른쪽 Ctrl)나 조합(Ctrl + Shift + Space)을 쓸 수 있습니다.
- Ctrl, Alt, Shift, Win 가운데 하나만 단축키로 정하면 다른 키 없이 그 키만 누를 때 동작합니다. 오른쪽 Ctrl + C처럼 다른 키와 함께 누르면 녹음하지 않습니다.

| 동작 방식 | 하는 일 |
|---|---|
| 토글 (기본) | 누를 때마다 녹음을 시작하고 끝냅니다. |
| 누르는 동안 | 누르고 있는 동안만 녹음합니다. |

한 번에 녹음하는 길이는 기본 120초까지이고, 이 길이에 닿으면 녹음을 끝내고 받아씁니다. **설정 → 오디오 → 최대 녹음 길이**에서 바꿉니다.
녹음 시작과 끝, 복사·입력은 효과음으로도 알려 줍니다. **설정 → 오디오 → 효과음**에서 끌 수 있습니다.

## 음성 인식

**모델 관리 → 음성 인식**에서 엔진과 모델을 고릅니다.

| 엔진 | 특징 |
|---|---|
| Whisper (로컬) | whisper.cpp로 이 컴퓨터에서 인식합니다. Tiny(약 78 MB)부터 Large v3(약 3.1 GB)까지 있습니다. |
| Whisper (로컬 ONNX) | ONNX Runtime으로 이 컴퓨터에서 인식합니다. GPU 가속에 DirectML을 씁니다. |
| SenseVoice (로컬 ONNX) | 한국어·영어·중국어·일본어·광둥어를 아주 빠르게 인식합니다. 약 240 MB부터 있습니다. |
| 클라우드 API (OpenAI 호환) | OpenAI, Groq 같은 OpenAI 호환 API로 음성을 보내 인식합니다. **외부 제공자** 탭에서 등록합니다. |

**사용 가능 모델** 탭에서 모델 카드를 펼치면 설정을 바꾸고 **테스트**로 바로 확인할 수 있습니다.

- **인식 언어**: 한국어·영어·중국어·일본어 가운데 모델이 지원하는 언어를 고릅니다. 자동 감지를 지원하는 모델도 있지만, 한 언어로만 말하면 그 언어를 고르는 편이 정확합니다.
- **GPU 가속**, **가속 장치**: 엔진에 따라 이름이 다릅니다. 쓸 수 있는 GPU가 없으면 CPU로 인식합니다.
- **모델 메모리 유지 시간(분)**: 이 시간 동안 쓰지 않으면 모델을 메모리에서 내립니다. 기본값은 5분입니다.
- **용어 힌트**: 자주 쓰는 용어나 이름을 적어 두면 더 정확히 알아듣습니다. Whisper (로컬)와 클라우드 API에서 쓸 수 있고, 모델 목록 아래에 있습니다.

## 글 다듬기

받아쓴 글을 프롬프트와 함께 언어 모델(LLM)에 보내고, 돌려받은 글을 받아쓴 글 대신 넣습니다.

1. **모델 관리 → 글 다듬기**에서 **사용**을 켭니다.
2. 다듬는 데 쓸 모델을 정합니다. 로컬 모델을 내려받거나, 외부 제공자를 등록하거나, **외부 제공자** 탭의 **Codex 로그인**에서 ChatGPT 계정으로 로그인하거나, 같은 탭의 **Claude Code CLI**를 추가합니다.
3. **프롬프트** 화면에서 쓸 프롬프트를 켭니다. 처음에는 **기본 다듬기**가 켜져 있습니다.

### 모델

| 종류 | 고를 수 있는 것 |
|---|---|
| 로컬 모델 | Qwen3.5, Gemma 4, EXAONE 3.5(비상업적 용도 전용). `추천` 표시는 Qwen3.5 4B(약 2.7 GB)에 붙어 있습니다. |
| Codex 로그인 | ChatGPT 계정으로 로그인해 Codex가 쓰는 모델(gpt-6-luna 등)로 다듬습니다. API 키가 필요 없고, 사용량은 그 계정의 ChatGPT 요금제에서 차감됩니다. |
| Claude Code CLI | 이 PC에 설치하고 로그인해 둔 Claude Code CLI(`claude`)로 다듬습니다(sonnet, opus, haiku, fable 등). API 키가 필요 없고, 사용량은 CLI에 로그인한 Claude 계정의 요금제에서 차감됩니다. 다듬을 때마다 CLI를 새로 띄워 한 번에 몇 초 더 걸립니다. |
| 외부 제공자 | OpenAI, Anthropic, Google Gemini, xAI, Mistral AI, DeepSeek, Groq, OpenRouter, Together AI, Fireworks AI, Cerebras, Cohere, Upstage, 네이버 CLOVA Studio, Alibaba Cloud Model Studio, Moonshot AI (Kimi), Ollama, LM Studio, 그 밖의 OpenAI 호환 서버 |

- 외부 제공자는 주소, API 키, 모델 이름을 넣고 **연결 테스트**를 통과한 뒤 **등록**을 누릅니다.
- Codex 로그인은 **외부 제공자** 탭 아래쪽의 **Codex 로그인** 카드에서 **브라우저에서 로그인**을 누르고 열린 브라우저에서 로그인을 마칩니다. 로그인하면 **사용 가능 모델**에 Codex 카드가 생기고, 카드에서 모델과 추론 단계를 고릅니다. 로그인 정보는 Codex CLI와 따로 저장해서, 술술에서 로그아웃해도 Codex CLI는 로그인된 채로 남습니다.
- Claude Code CLI는 **외부 제공자** 탭 맨 아래의 **Claude Code CLI** 카드에서 위치·판·로그인 상태를 확인하고 **사용 가능 모델에 추가**를 누릅니다. CLI는 PATH와 흔한 설치 위치에서 찾고, 못 찾으면 **CLI 위치**에 `claude` 실행 파일의 경로를 적습니다. 로그인은 술술이 아니라 터미널에서 `claude`를 실행해 `/login`으로 합니다. 다듬을 때는 도구·MCP 서버·CLAUDE.md 같은 사용자 설정을 끄고 실행합니다.
- 생각하는 모델은 답이 늦을 수 있습니다. **추론 단계**를 낮추거나 끄면 더 빨리 받습니다. 제공자에 따라 고를 수 없는 단계도 있습니다.
- 다듬은 결과는 모델마다 다릅니다. **테스트** 화면에서 몇 문장 다듬어 보고 고르세요.
- 소스에서 빌드해 쓸 때 로컬 모델을 돌리려면 실행기(`sulsul-llm-runner`)를 따로 빌드해야 합니다. 명령은 [개발 안내](development.md#명령)에 있습니다.

### 프롬프트

프롬프트는 모델에게 글을 어떻게 다듬을지 알려 주는 지시문입니다. 켠 프롬프트 하나로 다듬고, 고쳐 쓰거나 새로 만들 수 있습니다. 처음에는 두 개가 들어 있습니다.

| 프롬프트 | 하는 일 |
|---|---|
| 기본 다듬기 | 군말과 되풀이한 말을 빼고, 말하다 고친 곳은 고친 쪽만 남기고, 맞춤법·띄어쓰기·문장 부호를 바로잡습니다. 뜻과 말투는 바꾸지 않습니다. |
| 개발 지시 정리 | 두서없이 말한 개발 요청을 Claude Code, Codex, Cursor 같은 코딩 에이전트에게 보낼 작업 지시로 정리합니다. 목표, 배경, 요구 사항, 제약, 완료 기준 같은 항목으로 나눠 씁니다. |

### 다듬지 못했을 때

받아쓴 원문 대신 `[술술 오류]`로 시작하는 안내를 같은 곳에 넣습니다. 받아쓴 원문은 **기록** 화면에 남아 있어 거기서 복사할 수 있습니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 테스트 | 녹음, 받아쓰기, 글 다듬기를 한 단계씩 해 보고 결과와 걸린 시간을 봅니다. 방금 한 녹음을 들어 보거나 WAV 파일을 열어 받아쓸 수도 있습니다. |
| 기록 | 단축키로 받아쓴 글을 최근 200개까지 보여 줍니다. 카드를 펼치면 다듬은 글과 받아쓴 원문을 따로 복사하거나 기록을 지울 수 있습니다. |
| 모델 관리 | 음성 인식과 글 다듬기에 쓸 모델을 내려받고, 외부 제공자를 등록하고, 쓸 것을 켭니다. |
| 프롬프트 | 글 다듬기에 쓸 프롬프트를 고치고, 새로 만들고, 켭니다. |
| 설정 | 테마, 자동 실행, 받아쓰기 결과, 단축키, 입력 장치, 최대 녹음 길이, 효과음을 바꿉니다. 바꾼 값은 바로 저장됩니다. |
| 정보 | 버전을 확인하고, 설정 파일과 데이터·모델·로그 폴더를 엽니다. |

## 설정 파일과 기록

설정은 TOML 파일 하나에 저장됩니다. 설정 화면에서 바꾼 값은 바로 이 파일에 저장되고, 파일에 직접 써 둔 주석도 그대로 남습니다.
앱이 켜져 있을 때 파일을 직접 고치면 자동으로 다시 읽습니다.

| 무엇 | 위치 (Windows) |
|---|---|
| 설정 파일 | `%APPDATA%\sulsul\config\config.toml` |
| 데이터 폴더 (모델·기록·로그) | `%LOCALAPPDATA%\sulsul\data` |
| 받아쓰기 기록 | 데이터 폴더의 `history.json` |
| Codex 로그인 정보 | 데이터 폴더의 `codex\auth.json` (로그아웃하면 지웁니다) |
| 앱 로그 | 데이터 폴더의 `logs\sulsul.log` (5 MB를 넘으면 `sulsul.old.log`로 옮기고 새로 씁니다) |

- **설정** 화면 맨 위의 **설정 파일 열기**와 **정보** 화면의 파일 위치에서 바로 열 수 있습니다.
- 외부 제공자의 API 키도 설정 파일에 들어 있습니다. 파일을 남에게 보여 줄 때는 키를 지우세요.
- Codex 로그인 정보(`codex\auth.json`)는 계정에 로그인할 수 있는 열쇠입니다. 남에게 주지 마세요.
- 로그에는 받아쓴 글과 API 키를 남기지 않습니다.

## 자주 묻는 질문

**음성이나 글이 인터넷으로 나가나요?**

로컬 엔진(Whisper, SenseVoice)과 로컬 다듬기 모델만 쓰면 음성과 글이 컴퓨터 밖으로 나가지 않습니다. 인터넷은 모델을 내려받을 때만 씁니다.
음성 인식에 클라우드 API를 고르면 음성이, 글 다듬기에 외부 제공자를 고르면 받아쓴 글이 그 서비스로 보내집니다.

**GPU가 없어도 되나요?**

됩니다. 쓸 수 있는 GPU가 없으면 CPU로 인식합니다. 큰 모델은 CPU에서 느릴 수 있으니 작은 모델부터 써 보세요.

**오랜만에 받아쓰면 처음 한 번이 느려요.**

쓰지 않는 동안 내려 둔 모델을 메모리에 다시 올리기 때문입니다. 모델은 5분 동안 쓰지 않으면 내립니다.
더 오래 두려면 **모델 관리 → 음성 인식 → 사용 가능 모델**에서 모델 카드를 펼쳐 **모델 메모리 유지 시간(분)** 값을 늘리세요.

**실패음만 나고 글이 나오지 않아요.**

술술 창을 열어 두고 다시 해 보면 이유가 알림으로 뜹니다. 흔한 경우는 이렇습니다.

- 녹음에서 말소리를 찾지 못했습니다. 마이크가 음소거되지 않았는지, **설정 → 오디오 → 입력 장치**가 맞는지 확인하세요. **테스트** 화면에서 녹음해 보면 음량이 보입니다.
- 음성 인식 모델을 아직 내려받지 않았습니다. **모델 관리 → 음성 인식**에서 내려받으세요.
- 받아쓰기 결과가 **커서 위치에 붙여넣기**인데 입력 중인 곳이 없었습니다. 받아쓴 글은 **기록** 화면에 남아 있습니다.

**`[술술 오류]`로 시작하는 글이 들어왔어요.**

글 다듬기에 실패해서 그 이유를 알려 주는 글입니다. 받아쓴 원문은 **기록** 화면에서 복사할 수 있습니다.
로컬 모델이라면 모델을 내려받았는지, 외부 제공자라면 API 키와 주소가 맞는지 확인하세요.

**붙여넣고 나니 클립보드에 받아쓴 글이 없어요.**

**클립보드 되돌리기**가 켜져 있으면 한 번 붙여넣은 뒤 클립보드를 원래 내용으로 되돌립니다. 받아쓴 글은 **기록** 화면에서 다시 복사할 수 있습니다.

**창을 닫았는데 계속 실행 중이에요.**

창을 닫으면 알림 영역(트레이)으로 들어가 단축키를 계속 받습니다. 끝내려면 트레이 아이콘 메뉴에서 **끝내기**를 누르세요.
